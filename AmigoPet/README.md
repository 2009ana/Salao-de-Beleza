# AmigoPet - versão simples

Esta versão foi feita pensando em um projeto escolar fácil de entender.

Tecnologias:
- HTML
- CSS
- JavaScript

Evitei frameworks, bibliotecas e estruturas avançadas.

Funciona diretamente abrindo o arquivo `index.html`.

O site possui:
- Página inicial
- Lista de pets
- Busca
- Filtros
- Favoritos
- Detalhes do pet
- Botão de adoção
- Formulário de contato
- Layout para celular

Observação:
Esta versão é propositalmente simples. Para usar banco de dados e login de administrador, seria necessário acrescentar um backend. A estrutura foi simplificada para que o código fique compatível com o que normalmente é aprendido em HTML, CSS e JavaScript no ensino médio/técnico.
